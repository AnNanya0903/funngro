# Funngro Website SEO Audit Report

Audit date: 7 October 2026. Site audited: https://funngro-gilt.vercel.app (deployed redesign).

## 1. Executive Summary

The redesign is fully static, ships unique metadata per page, uses clean URLs and includes
structured data (Organization, WebSite, BreadcrumbList, FAQPage). Lighthouse was run on the
deployed site at 320px (mobile) and 1440px (desktop). All four core categories scored 99-100.

## 2. Technical SEO

- Metadata: unique title and meta description on every page. Open Graph and Twitter tags
  generated by `createMetadata()` in src/lib/seo.ts.
- Canonical: set per page via `alternates.canonical`, derived from `NEXT_PUBLIC_SITE_URL`.
- Robots and sitemap: generated by Next.js (`src/app/robots.ts`, `src/app/sitemap.ts`).
  All 9 public routes are listed.
- Structured data: Organization, WebSite (no fake SearchAction), BreadcrumbList, FAQPage.
- URL structure: /, /teen, /for-brands, /how-it-works, /team, /privacy, /terms,
  /sitemap.xml, /robots.txt.

## 3. On-Page SEO

One H1 per page, logical H2/H3 order, descriptive internal links, text alternatives for
non-decorative visuals. Keywords used naturally: young Indians, earning opportunities,
youth marketing, reach young consumers.

## 4. Content SEO

Copy avoids invented statistics. The only figure used is 70 lakh young Indians, as stated on
funngro.com. Demo content is labelled as examples.

## 5. Mobile UX

Mobile-first layout, hamburger menu, no fixed-width elements. Verified at 320px and 1440px
with Lighthouse (see Section 10).

## 6. Accessibility

Skip link, visible focus, aria-pressed toggles, live regions, reduced-motion support.
Lighthouse accessibility score: 100 on both form factors.

## 7. Performance

Static generation, next/font, no heavy dependencies. Lighthouse performance: 99 (mobile),
100 (desktop). Core Web Vitals are green on both form factors (see Section 10).

## 8. Structured Data

Validate in the Rich Results Test after deployment. FAQPage and Organization schema are
present and passed Lighthouse's structured-data audit.

## 9. Keyword Opportunities

Teen: online earning opportunities for young Indians, student earning opportunities.
Companies: youth marketing platform India, Gen Z marketing India.

## 11. Priority Issues

- Critical: none remaining. The site is crawlable, server-rendered static HTML.
- High: none remaining. Unique meta descriptions and canonicals on every page.
- Medium: Resend requires a verified sending domain before the contact form can send mail.
- Low: add alt text and dimensions to all images (already handled for decorative SVGs).

## 12. Recommendations

Keep one canonical host, keep Organization and FAQ schema, publish a sitemap (already done).
Verify structured data in the Rich Results Test after deployment.
